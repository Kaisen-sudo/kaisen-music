# 🎵 Kaisen Music

![Kaisen Music](public/favicon.svg)

**Kaisen Music** est un clone moderne d'Audiomack avec une interface en verre dépoli (glassmorphism), un thème sombre/clair, des animations fluides et des icônes SVG personnalisées.

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)

![Tailwind](https://img.shields.io/badge/Tailwind-3.3.5-06B6D4.svg)

---

## ✨ Fonctionnalités

- 🎨 **Interface Glassmorphism** - Design moderne avec effets de verre dépoli
- 🌗 **Thème Sombre/Clair** - Basculement fluide entre les deux modes
- 🎬 **Animations fluides** - Transitions et micro-interactions avec Framer Motion
- 📱 **Responsive Design** - Adapté à tous les écrans (mobile, tablette, desktop)
- 🔍 **Recherche avancée** - Recherche de musiques, artistes et playlists
- 📊 **Charts en temps réel** - Classements quotidiens, hebdomadaires, mensuels et annuels
- 🎧 **Lecteur audio intégré** - Écoute des morceaux directement dans l'application
- 👤 **Pages artistes** - Profils détaillés avec discographie
- 🎼 **Playlists** - Affichage et gestion des playlists
- 🚀 **Performance optimisée** - Build rapide avec Vite
- 🔗 **API Audiomack** - Données en temps réel via l'API officielle

## 📦 Installation

### Prérequis

- **Node.js** >= 16.0.0
- **npm** >= 8.0.0 ou **yarn** >= 1.22.0

### Étapes d'installation

```bash
# 1. Cloner le repository
git clone https://github.com/votre-username/kaisen-music.git

# 2. Accéder au dossier
cd kaisen-music

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev
